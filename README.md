Multiplier iOS Application

8/31/2016

This iOS application tests the user's simple arithmetic ability by providing the user with a simple math expression with four options for the user to select as the solution.

The user can select among four choices for what type of operation is used for the expressions. Addition, Subtraction, Multiplication, Division, and "Combo". The "Combo" option randomly chooses an operation for each expression used.

The user can also select the number of expressions that are asked for one round of gameplay. Five (5), Ten (10), Fifteen (15), or Twenty (20).

Once the user selects the type of operation and the number of expressions, the gameplay consists of the user selecting among four options for the correct answer to the provided expression. The application provides the user simple feedback on whether or not he or she was correct in his or her guess for the solution.

Once the requested number of expressions is complete, the user is brought back to the original menu to select the two options again for another round of gameplay.
